# Implementation verification

Date: 2026-10-24. Change: `modernize-cpp23-raii`. This report records evidence;
final native CI and review acceptance are still in progress.

The C++23 `jamnntpd` server now integrates the network loop, owned worker lifecycle,
NNTP session engine, permissions, MIME/text conversion, spdlog and JAM backend.
Both production executables build. All forty historical C/header/Makefile hashes
were checked before removing those files; notices and license texts were retained.

Coverage merges all five executable objects and rejects missing production C++
translation units. Own headers and error branches are included. Linux and macOS
reports do not cover inactive Windows branches; native Windows adapter evidence is
required separately. Reports and denominators are generated by
`tools/check_coverage.py`; raw local artifacts remain in ignored build directories.

The executable suite covers all characterized NNTP commands, authentication,
guest/read/post/netmail permissions, read/post/reply/cancel, every supported standard
encoding, custom CHS, byte-pass-through, strict refusal without mutation, replacement,
oversized/incomplete POST, command injection, log redaction, admission/configuration
failures and complete backup restoration. `/dev/full` is native Linux evidence;
injected sink-failure tests run on every platform. The 100-round stress test combines
concurrent posting, reads and cancellation with independent native JAM locking and
bounded shutdown. It checks every companion file after blocked-post shutdown.

Permanent quarantine tests run in separate processes because quarantine intentionally
survives handle closure and conservatively rejects recycled filesystem identities.
This preserves the production safety contract while preventing one destructive test
from poisoning later fixtures through rapid inode reuse. Assertions remain intact.

TSan initially reported ICU converter-cache mutex initialization when ICU was not
instrumented. The first custom toolchain also failed to propagate flags into ICU's
autotools build. After explicitly chaining the vcpkg Linux toolchain, actual ICU
compile flags contained `-fsanitize=thread`; the full suite then passed without
suppressions. CI uses this instrumented dependency configuration.

Native CI is attached to draft PR https://github.com/hashev/jamnntpd/pull/1.
The initial macOS 15 runner lacked jthread support; CI now selects macOS 26 and
configure probes expected/jthread/stop_token. Linux Clang selects the GCC 14 standard
library explicitly to avoid silently picking another installed GCC library.

User-confirmed compatibility decisions remain: table-less explicit rules preserve
bytes; `-builtin` opts into standard conversion. Recoverable I/O errors rollback;
persistent rollback failure quarantines the base and requires consistent backup
restore plus restart. No journal, physical-disk availability or power-loss atomicity
is claimed. See rehearsal.md and storage.md for operational limits.

Initial native Windows compilation exposed an assumption that std::array iterators
are pointers. Portable value/position lookups now replace that assumption (R33).
Windows dependencies were installed cleanly and their pinned binary cache is saved;
corrected native executable and coverage results are still required. CTest starts
Python explicitly in UTF-8 mode, and executable tests verify Unicode config/map paths.
